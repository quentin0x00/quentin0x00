Géomaticien, Mouton à 5 Pattes 🐏

J'administre des **SGBD spatiaux**, j'automatise les **traitements de données** et je gère des **portails web-carto**. 

## Technologies utilisées

- **PostGIS** : Gestion des bases de données géospatiales.
- **Python** : Automatisation des traitements géospatiaux.
- **GeoServer** : Publication de services cartographiques.
- **QGIS** : Visualisation et analyse des données géospatiales.
- **GDAL** : Traitement des formats géospatiaux.
- **Airflow** : Automatisation des workflows.
- **MapLibre** : Cartes interactives sur le web.
- **Flask** : API pour l'intégration des services géospatiaux.
- **Git** : Gestion de version.
