## GEOMATICIEN, mouton à 5 pattes.                                                                                                               
                                                                                      
J'administre des **SGBD spatiaux**, j'automatise les **traitements de données** et je gère des **portails web-carto**. 
## Technologies utilisées
                                                                           
+---------------------------------------------------+
|          🌍 Outils Géomatiques Utilisés           |
+---------------------------------------------------+
|  - PostGIS          : Gestion des SGBD spatiaux    |
|  - Python           : Automatisation des traitements|
|  - GeoServer        : Publication des cartes      |
|  - Martin           : Génération de tuiles PMTiles |
|  - QGIS             : Visualisation et analyse    |
|  - GDAL             : Traitement de formats       |
|  - Airflow          : Automatisation des workflows|
|  - VMap             : Gestion des données vectorielles|
|  - MapLibre         : Cartes interactives sur le web|
|  - Flask            : API pour intégration géospatiale|
|  - Git              : Gestion de version         |
|  - Docker           : Containerisation des services|
|  - HTML             : Structure des pages web     |
|  - CSS              : Style des pages web         |
|  - JS (JavaScript)  : Interaction dynamique web   |
+---------------------------------------------------+
